# Interactive Color Picker

## Description
Interactive Color Picker is a simple web tool for students and beginners to practice HTML, CSS, and JavaScript. Pick a color, see it live in a preview, and track your previous selections in a color history. Perfect for learning interactive UI and DOM manipulation.

**Project Type:** Learning / Practice  
**Target Audience:** Students, beginners learning HTML, CSS, and JavaScript  

---

## Overview

This project is an **Interactive Color Picker** designed to help students practice web development concepts. It allows users to:

- Pick colors using a color input  
- See the selected color in a live preview box  
- Keep track of previously selected colors (color history)  
- Clear the history when needed  

The project demonstrates practical use of **DOM manipulation, events, and styling** in JavaScript.

---

## Features

- **Live Color Preview:** Updates instantly as the user selects a color  
- **Color History:** Keeps track of previously chosen colors as clickable boxes  
- **Responsive Design:** Works on both desktop and mobile  
- **Clear History:** Button to reset the color history  

---

## How It Works

1. User selects a color using the color input field.
2. The preview box updates immediately to show the selected color.
3. The selected color is added to the history list as a clickable box.
4. Clicking a color in history sets it as the active color again.
5. The "Clear History" button removes all previous colors from the history list.
